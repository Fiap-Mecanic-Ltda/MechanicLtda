07Diagrama de componentes

Entrada únicaToda chamada externa à API passa pelo API Gateway. A porta 8080 dos nós aceita apenas o security group do ALB interno.
Autorização em duas camadasO authorizer autentica e filtra a role por rota antes do backend; a API decide a posse do recurso.
Dados privadosO RDS fica em sub-redes privadas. O CPF é gravado cifrado e localizado por um hash HMAC.

08Decisões que afetam a avaliação

  • Sem ambiente de homologação na AWS. As branches desenvolvimento e homologacao executam build, testes e terraform plan; só a main faz deploy. Um segundo ambiente dobraria o custo fixo do projeto (ADR-009).
  • Cliente autenticado por CPF só consulta. O token de cliente acessa apenas as próprias ordens de serviço; abertura e transições são da oficina (RFC-004).
  • Web Razor fora do gateway. A interface da oficina continua publicada na porta 8090; o gateway protege a API (RFC-001, seção 8).
  • Evoluções registradas. Login somente leitura no banco para a Lambda e segundo fator na autenticação por CPF estão documentados como próximos passos (documento do banco e RFC-004).
